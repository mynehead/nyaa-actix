Using the Site

{{ macros::linkable_header(heading="Torrent Colors", label="torrent-colors") }}
Green entries (trusted) are:
  • Torrents uploaded by trusted users.
Red entries (remake) are torrents that match any of the following:
  • Reencode of original release.
  • Remux of another uploader's original release for hardsubbing and/or fixing purposes.
  • Reupload of original release using non-original file names.
  • Reupload of original release with missing and/or unrelated additional files.
Orange entries are:
  • Batches of completed series.
Grey entries are:
  • Hidden torrents.
{{ macros::linkable_header(heading="Using the Search Engine", label="using-search") }}
Search results can be filtered by category, remake, trusted, and users. The results can be further sorted by size, date, seeders, leechers, completed count, and comment count.
A search finds torrents whose names contain every word you enter. These operators narrow it down:
  • "exact phrase" matches the words in that order.
  • -word or !word leaves out torrents containing the word; -"some phrase" works too.
  • user:name shows only that user's uploads, group:slug only that group's. Put a - or ! in front to leave them out instead, e.g. -group:slug.
  • An info hash (40 hex or 32 base32 characters) opens that torrent directly.
For example, group:subsplease "one piece" 1080p -batch.
{{ macros::linkable_header(heading="Reporting Torrents", label="reporting") }}
If you find a torrent that breaks the rules, click the button to the right of the torrent's information page. Then, enter a reason for your report in the dialog that opens, and hit the button to confirm.
{{ macros::linkable_header(heading="Styling Descriptions and Comments", label="styling") }}
You can style your comments and your torrent's description using Markdown. This includes adding images or linking to external websites.
To link to an external site, use [label](https://example.com) where the text in the [] square brackets is the shown text of your link, and the URL in the () parentheses is the URL your link will point to.
Embedding an image is similar. Use ![alt text](https://example.com/image.jpg) to have an image embedded in your comment or description. Note the ! exclamation mark at the beginning, denoting that this link is an image.
{{ macros::linkable_header(heading="Changing Your User's Avatar", label="avatar") }}
The site uses the Gravatar service for user avatars. Check out Gravatar's help section for more detailed instructions.
{{ macros::linkable_header(heading="Deleting Your Torrent", label="delete") }}
If you wish to delete one of your torrents, navigate to the torrent's page, click the Edit () icon on the top left, scroll down and hit the button.
{{ macros::linkable_header(heading="Getting Trusted Status", label="trusted") }}
At the moment we have no established process for granting trusted status to users who did not previously have it. If and when we establish such a process it will be announced.
