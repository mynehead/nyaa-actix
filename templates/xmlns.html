The nyaa XML namespace

The site's RSS feeds (/?page=rss, or /rss) add these elements to each item:

nyaa:seeders
Seeders, as last reported by the tracker.
nyaa:leechers
Leechers, as last reported by the tracker.
nyaa:downloads
Completed downloads.
nyaa:infoHash
The torrent's info hash, in lowercase hex.
nyaa:categoryId
Category as main_sub, the value of the c= search parameter.
nyaa:category
Category name.
nyaa:size
Total size of the torrent's files, in binary units.
nyaa:comments
Number of comments.
nyaa:trusted
Yes if uploaded by a trusted user.
nyaa:remake
Yes if marked as a remake.
nyaa:best
Yes if staff marked it as one of the best releases (not in upstream nyaa).

Feeds take the same parameters as the listing (q, c, f, u, s, o, p). Add &magnets to link items to magnet URIs instead of .torrent files.
